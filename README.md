# ESP32_learning

Notes and code from working through ESP32 tutorials.

**Environment:** Ubuntu, Arduino IDE 2.x, ESP32 Dev Module (`/dev/ttyUSB0`).

## Structure

- Each component/topic gets its own folder. A folder contains the Arduino sketch(es).
- A notes file (PDF) with what I learned, wiring, and any issues hit

## Setup

Arduino IDE 2.x with ESP32 board support installed (board profile "ESP32 Dev Module"). Follow ELEGOO's `download and install` and `First look ESP32` wiki guides for board manager URL and driver setup.

## Reference

Tutorials and wiring diagrams follow the [ELEGOO ESP32 Wiki](https://www.elegoo.com/).

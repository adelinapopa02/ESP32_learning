# ESP32_learning

Notes and code from working through the ELEGOO ESP32 starter kit tutorials, as prep for a personal ESP32 + ROS 2 SLAM robot project.

**Environment:** Ubuntu, Arduino IDE 2.x, ESP32 Dev Module (`/dev/ttyUSB0`).

## Structure

Each component/topic gets its own folder. A folder contains:
- the Arduino sketch(es)
- a notes file (PDF or Markdown) with what I learned, wiring, and any issues hit
